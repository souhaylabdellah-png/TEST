# 🇲🇦 Site Web Maroc - Minimaliste & Moderne

Un site web moderne et minimaliste dédié au Maroc avec un thème bleu et blanc élégant.

## 🎨 Caractéristiques

- **Design Minimaliste**: Interface épurée et intuitive
- **Thème Bleu & Blanc**: Palette de couleurs professionnelle et moderne
- **Responsive**: Adapté à tous les appareils (mobile, tablette, desktop)
- **Dynamique**: Animations fluides et interactions utilisateur
- **Performance**: Chargement rapide et optimisé
- **Accessible**: Navigation claire et utilisation facile

## 📱 Sections

1. **Navigation Sticky**: Menu toujours accessible en défilant
2. **Hero Section**: Accueil accrocheur avec CTA
3. **À propos**: Découvrez la richesse du Maroc
4. **Services**: Nos services touristiques et voyages
5. **Contact**: Formulaire de contact interactif
6. **Footer**: Liens sociaux et informations

## ✨ Fonctionnalités Dynamiques

- Navigation mobile avec menu hamburger
- Scroll smooth vers les sections
- Animations au défilement
- Formulaire de contact avec validation
- Parallaxe léger sur les éléments
- Hover effects sur tous les boutons et cartes
- Responsive design complet

## 🚀 Utilisation

1. Ouvrez `index.html` dans un navigateur
2. Explorez les différentes sections
3. Testez le formulaire de contact
4. Profitez du design moderne!

## 📂 Structure du Projet

```
├── index.html      # Structure HTML
├── style.css       # Styles et design
├── script.js       # Interactions dynamiques
└── README.md       # Documentation
```

## 🎯 Technos Utilisées

- **HTML5**: Sémantique moderne
- **CSS3**: Animations et layouts flexibles
- **JavaScript Vanilla**: Interactivité sans dépendances

## 🌐 Adapté Pour

- Marocains et résidents au Maroc
- Touristes intéressés par le Maroc
- Agences de voyage
- Guides touristiques
